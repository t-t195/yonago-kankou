# 00. ヒアリングシート

| 案件名 | 　 | 記入日 | 　 |
|---|---|---|---|
| ステータス | 下書き / 回答待ち / 完了 | 回答者 | 　 |

> 発注者(またはサイトオーナー)に回答してもらう質問票。**ここの精度が最終クオリティの7割を決める**。空欄のまま次フェーズへ進まないこと。「わからない」も回答として記録し、リサーチで補う対象に印を付ける。

## A. 事業について

1. 事業内容を一言で言うと？（誰に・何を・どうやって提供しているか）
2. 主力商品・サービスと価格帯は？
3. 顧客はどこから来ているか？（紹介/検索/SNS/広告/飛び込み…比率も）
4. 競合だと思う会社・サービスを3つ挙げると？それぞれどこが脅威か？
5. 顧客に「選ばれている理由」を顧客の言葉で言うと？（実際に言われたこと）
6. 逆に「断られる/負ける理由」は？

## B. 代表・会社の思想（E-E-A-T / 代表メッセージの素材）

7. この事業を始めた原体験・きっかけは？
8. 5年後どうなっていたいか？（事業・地域・顧客との関係）
9. 仕事で絶対に譲らないこだわりは？
10. 実績・資格・受賞・メディア掲載・取引社数など、信頼の根拠になる事実は？

## C. サイトの目的

11. サイトで一番起こしたい行動は？（問い合わせ/予約/資料DL/採用応募/指名検索…**1つに絞る**）
12. その行動を月に何件起こせたら成功か？
13. 誰に一番見てほしいか？（年齢/性別/地域/状況/悩み — 実在の顧客1人を想定）
14. その人はサイトに来る前、何に困って何を検索しているか？
15. 見た人に「どう感じてほしい」か？（形容詞3つ。例: 誠実/先進的/あたたかい）

## D. 素材・制約

16. 使えるもの: ロゴ / 写真 / 会社案内 / 実績データ / お客様の声 / 動画（有無と所在）
17. 参考にしたいサイト・嫌いなサイト（URLと理由）
18. 公開希望日と、その日である理由
19. 予算感（制作費 / 月額の維持費・広告費）
20. ドメイン・サーバー・解析ツールの既存契約は？（ID管理者も）
21. 更新は誰がやるか？（更新頻度・更新したい箇所）

## E. 記入後の処理

- [ ] 「わからない」回答に印 → `02_research.md` の調査項目へ転記
- [ ] 矛盾する回答（例: ターゲット若年層なのに参考サイトが官公庁風）を確認質問リスト化
- [ ] 回答を `01_project-brief.md` に要約・構造化
