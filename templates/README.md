# templates/ — 設計書・仕様書の型

サイト/LP制作の各フェーズで使う仕様書テンプレート。**案件ごとに `projects/<案件名>/` へコピーして埋める**（型本体は直接編集しない）。

| ファイル | フェーズ | 一言でいうと |
|---|---|---|
| `00_hearing-sheet.md` | ヒアリング | 発注者への質問票。精度の7割はここ |
| `01_project-brief.md` | 要件定義 | 目的・KGI/KPI・スコープの「正」 |
| `02_research.md` | リサーチ | 「何を言えば選ばれるか」の特定 |
| `03_site-structure.md` | 構成 | 訴求をページ・セクション順に翻訳 |
| `04_wireframe.md` | WF | レイアウト確定（装飾はまだ） |
| `05_design-system.md` | デザイン | 印象→視覚言語の翻訳。全項目に「なぜ」 |
| `06_content-copy.md` | 原稿 | 構築前に全文章FIX。法務チェック込み |
| `07_build-spec.md` | 構築 | 技術選定・規約・性能予算・費用確認 |
| `08_seo-aio-checklist.md` | SEO/AIO | 構造化データ・E-E-A-T・AI引用対策 |
| `09_qa-checklist.md` | 検証 | 自動+実機+コンテンツ突き合わせ |
| `10_launch-operation.md` | 公開・運用 | 公開手順・引き継ぎ・月次改善 |

運用ルールと全体フローは [../WORKFLOW.md](../WORKFLOW.md) を参照。
