# 学習ログテンプレート（logs/day-XX.md）

Notion転記（notion-sync）はH1をページタイトルに使うため、H1は必ず「Day XX：テーマ」形式にする。
以下の必須項目をすべて含めること。回答・フィードバックは要約でよい（全文転記しない）。

```markdown
# Day 8：ClaudeとGeminiを検証し、メインAIを選定する

日付：2026年6月12日（金）／Week 2

## テーマ

（このDayのねらいを2〜3行で）

## 質問1：（小見出し）

問い：（出題の要約）
谷本さんの回答：（回答の要約。本人の言葉のニュアンスを残す）
フィードバック要約：（指摘・補足の要点。【補足A/B/C】ラベルはそのまま使う）

## 質問2：（同上）

## 質問3：（同上）

## 今日のキーワード

- 用語（読みがな）：一行説明
- ...

## 復習ポイント

- （次回以降に確認すべき弱点・取りこぼし。review_queueに積んだものと一致させる）

## 予習ポイント

- （明日のDayのテーマと、考えておくとよい問い）
```

## 週次Day（5の倍数）の追加セクション

質問セクションの前に以下を追加する。

```markdown
## 週の振り返り（Day XX〜XX）

- キーワード総ざらい：
- できるようになったこと：
- 課題：

## 小テスト

### テスト1（前週復習）：...
### テスト2（言語化）：...
### テスト3：...

結果：pass / retry（弱点：...）
```
