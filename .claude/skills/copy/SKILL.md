# コピーライティング skill

## 目的
構築前に全文章を確定させる。コピーはセンスではなく**リサーチ(02)の発見の言語化**。

## 入出力
- 入力: `02_research.md`（ポジショニング・訴求優先順位・ペルソナの不安）、`03_structure.md`
- 出力: `projects/<案件名>/06_content.md`（全原稿FIX）

## 手順
1. コアコピーから着手。キャッチコピーは方向性の違う案を3本（ベネフィット直球 / 数字・実績 / 情緒・ストーリー）出し、それぞれ根拠（02のどの発見か）を添えて選んでもらう
2. CTA文言: 「送信」「お問い合わせ」禁止。行動で得られる価値を書く＋直前のマイクロコピーで最後の不安を打ち消す
3. セクション原稿: 03の構成表の順に執筆。1セクション=1メッセージ。見出しだけ拾い読みして意味が通るかを確認
4. FAQ: ペルソナの不安リスト(02-5)と「実際に顧客から聞かれる質問」(ヒアリング)から作成。質問文はユーザーの言葉、回答は結論ファースト2〜4文（AI検索の引用単位を意識）
5. E-E-A-T情報（運営者・代表メッセージ）を確定。代表メッセージは「原体験→こだわり→未来」の3段構成
6. メタ情報（title/description）を全ページ分執筆
7. 法務チェック（景表法・業種別規制・掲載許可）を実施し、リスク箇所を指摘
8. 06のコピー品質チェック4項目を全コピーに適用してから原稿FIXの承認を取る

## 品質基準
- 主語が顧客（「私たちは〜できます」→「あなたの〜が解決します」）
- 抽象語に数字の裏付け（「豊富な実績」→「導入120社」）
- そのコピーを競合サイトに貼っても成立してしまうなら書き直し

## アンチパターン
- デザインカンプ上で文章を書く・直す（必ず原稿に戻して履歴を残す）
- 根拠のない最上級表現（No.1・最安・絶対）
- 社内用語・専門用語をそのまま使う
