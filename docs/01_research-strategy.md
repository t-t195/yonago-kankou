# 01. リサーチ & サイト戦略

最終更新: 2026-06-12

## 1. サイトの目的と役割

| 項目 | 内容 |
|---|---|
| サイト名 | 米子観光ガイド（DISCOVER YONAGO） |
| 種別 | 地域観光情報サイト + 運営事業者の信頼性提示（事業用HP/LP） |
| 一次目的 | 「米子 観光」「米子 旅行 モデルコース」等の検索・AI検索からの流入獲得 |
| 二次目的 | 運営事業者（代表）の認知・信頼獲得、問い合わせ導線の確保 |
| ターゲット | (1) 米子・大山エリアへの旅行検討者（家族/カップル/一人旅） (2) アート・歴史目的の趣味旅行者 (3) 出張ついでの観光客 |
| KGI | 問い合わせ・回遊（モデルコース閲覧）数 |
| KPI | 検索流入数、AI検索での引用、FAQ到達率、滞在時間 |

## 2. 業界リサーチ（観光情報サイト業界）

- 旅行情報の入口は「Google検索 → AI Overviews / ChatGPT等のAI検索」へ移行中。2026年5月時点で Google 検索クエリの約48%に AI Overviews が表示されるとの調査がある。
- 公式系（自治体・観光協会）は網羅性で強いが、「個人の体験」「比較・本音評価」「目的別の意思決定支援」が弱い。
- ユーザーの検索行動は「スポット名」より「誰と・何をしたい・いくらで」という目的起点が増加。→ 目的別・料金比較・モデルコースのコンテンツが差別化点。

## 3. 競合他社

| 競合 | URL | 強み | 弱み（＝当サイトの機会） |
|---|---|---|---|
| 米子観光ナビ（米子市観光協会） | https://www.yonago-navi.jp/ | 公式の網羅性・正確性 | 比較・評価・本音レビューがない |
| とっとり旅（鳥取県公式） | https://www.tottori-guide.jp/ | 県全域の情報量、モデルコース | 米子特化の深掘りが薄い |
| 旅色 / フォートラベル / KNT 等の大手メディア | https://tabiiro.jp/ ほか | ドメインパワー、写真 | 地元視点・更新性・一次体験が弱い |
| ANA等の交通系観光ページ | https://www.ana.co.jp/ | 送客力 | 深い現地情報なし |

**ポジショニング**: 「公式より本音、メディアより地元」。8スポットに絞った厳選・比較・目的別提案で、網羅型と差別化する。

## 4. 自社の特徴と強み（サイトに反映）

- 地元在住者の一次体験に基づく評価（★評価・感情タグ・本音コメント）
- 「料金比較」「目的別」「モデルコース」という意思決定直結の編集
- 厳選8スポット = 情報過多にしない編集方針
- ※運営者の実名・実績・写真は E-E-A-T 上必須 → サイト内【要編集】箇所に記入が必要

## 5. 代表メッセージの設計方針

- 「なぜ米子の観光情報を発信するのか」（地元への思い・原体験）
- 「見据える未来」（観光客と地元事業者をつなぐ、地域経済への貢献）
- 顔写真 + 実名 + 経歴を推奨（AI検索の引用判断でも著者情報が重視される）
- 本文はサイト内にプレースホルダで用意済み →【要編集】

## 7. AIO・SEO対策（実装内容）

2026年5月の Google 発表では「AI検索対策は通常のSEO（良質なコンテンツ + 構造化データ + E-E-A-T）で十分。llms.txt 等の単独施策の効果は未確認」とされた。これを踏まえ以下を実装する。

### 実装済み
- セマンティックHTML（h1-h3階層、header/main/section/footer、テーブル・definition型コンテンツ）
- 構造化データ JSON-LD: `WebSite` / `FAQPage` / `ItemList`(TouristAttraction) / `BreadcrumbList`
- title / meta description / OGP / canonical
- FAQ形式コンテンツ（AI検索が引用しやすい一問一答）
- 運営者・著者情報セクション（E-E-A-T）
- `sitemap.xml` / `robots.txt`
- `llms.txt`（効果未確認だがコストゼロのため設置。Google向けではなく他AIクローラ向けの保険）
- 表示速度: 静的HTML + 外部JSフレームワーク不使用（旧版の Tailwind CDN / Chart.js を削除）
- モバイルファースト・レスポンシブ

### 公開後にやること（要アカウント・無料）
- Google Search Console 登録 + sitemap送信
- Googleビジネスプロフィール（事業者として登録する場合）
- GA4 導入（無料。計測タグはサイト内コメントで挿入位置を明示済み）
