# Week 2. 上手な質問術 — プロンプトの基本

## この章で到達するゴール

- 「良い質問の5原則」を覚え、自分の質問に当てはめられる
- 悪い質問・良い質問の違いを具体例で説明できる
- 議事録要約／提案書たたき台／メール返信案を Claude にお願いできる
- 出力が期待と違ったときの**調整フレーズ**を使える

所要時間：1週間（毎日15〜30分の練習を想定）

---

## 2-0. 「プロンプト」とは？

**プロンプト** とは、AI に送る指示文のことです。料理に例えると、
- **食材** ＝ あなたが持っている情報（メール文・Excelデータ・議事メモなど）
- **レシピ** ＝ プロンプト（AI への指示）
- **料理** ＝ AI の返答（要約・提案書・メール案など）

**レシピが雑だと、料理も雑になります。** Claude を使いこなす=良いプロンプトを書けること、とほぼ同義です。

---

## 2-1. 良い質問の5原則（RGCFE）

覚えやすいよう、英語頭文字で **RGCFE（アールジーシーエフイー）** と呼びます。

| 原則 | 意味 | 例 |
|------|------|-----|
| **R**ole（役割） | Claude に役を与える | 「あなたは経験20年の営業部長です」 |
| **G**oal（目的） | 何を作りたいか | 「この議事録を3行で要約したい」 |
| **C**ondition（条件） | 守ってほしい制約 | 「300文字以内、丁寧語、専門用語は避ける」 |
| **F**ormat（形式） | 出力の形 | 「見出し＋箇条書き3点＋まとめ1文」 |
| **E**xample（例） | 参考イメージ | 「良い例：『◯◯が課題で、対策は△△』」 |

### すべて盛り込んだテンプレ

```
あなたは【役割】です。
以下の情報を元に【目的】をお願いします。
条件：
 ・【条件1】
 ・【条件2】
出力形式は【形式】にしてください。
参考例：【例】
---
（ここに情報を貼る）
```

このテンプレを iPhone の **メモアプリ** に保存して、毎回コピペして使うのがオススメです。

## 2-2. 悪い質問 vs 良い質問 — 10例比較

### 例1：メール要約

**❌ 悪い**
```
このメール要約して
```

**✅ 良い**
```
あなたは中小企業の総務部長です。
以下の取引先メールを、上司（部長）への報告用に3行で要約してください。
条件：
 ・結論→背景→次アクションの順
 ・敬語、200文字以内
---
（メール本文）
```

### 例2：提案書のたたき台

**❌ 悪い**
```
提案書作って
```

**✅ 良い**
```
あなたは AI 導入コンサルタントです。
「中堅製造業（従業員200名）への AI 活用提案書」のたたき台を作ってください。
条件：
 ・表紙／課題／解決策／費用感／導入スケジュール の5セクション
 ・各セクション 100〜200字
 ・専門用語は避ける
出力形式：見出し＋箇条書き
```

### 例3：アイデア出し

**❌ 悪い**
```
営業の効率化のアイデアちょうだい
```

**✅ 良い**
```
あなたは営業支援ツールの開発者です。
従業員30名の卸売業で「訪問後の日報作成に30分かかっている」課題を、
AI で解決する案を5つ出してください。
条件：
 ・追加コストが月1万円以内で済むもの優先
 ・それぞれ「使うAI・手順・効果」を1行ずつ
```

### 例4：議事録の清書

**❌ 悪い**
```
議事録まとめて
```

**✅ 良い**
```
あなたは議事録作成のプロです。
以下のメモを、社内の正式議事録フォーマットに整えてください。
条件：
 ・日時・出席者・議題・決定事項・宿題（担当/期日） の5項目
 ・不明な箇所は【要確認】と記載
---
（生メモを貼る）
```

### 例5：英語メールの返信

**❌ 悪い**
```
英語で返信書いて
```

**✅ 良い**
```
あなたは英語ビジネスメールのプロです。
以下の英文メールに、肯定的な返信を書いてください。
条件：
 ・ビジネスカジュアル
 ・5文以内
 ・次回ミーティングを再来週の火曜午前に提案
 ・末尾にサイン例（Taro Yamada, Planning Dept.）
```

### 例6〜10（要点のみ）

6. **表の整形**：「以下の売上データを、前年比%の列を追加した表に作り直して」
7. **文章の堅さ調整**：「この案内文を、新入社員向けに柔らかい言い回しで書き直して」
8. **英訳**：「このお礼文を、米国人取引先向けに英訳して。ただしフォーマル過ぎないトーンで」
9. **リスク洗い出し**：「この事業計画書の想定リスクを5つ、影響度・発生確率付きで」
10. **FAQ 作成**：「このマニュアルから想定される社員の質問を10件抽出し、回答案つきで」

## 2-3. 業務文書を作る 3 大パターン

### パターンA：議事録要約

**使うテンプレ**
```
あなたは熟練した秘書です。
以下の会議メモを「決定事項／保留事項／次回までの宿題」の3項目に分けてください。
宿題には担当者名と期日を明記。担当・期日が不明な場合は【要確認】と書く。
---
（会議メモを貼る）
```

### パターンB：提案書たたき台

**使うテンプレ**
```
あなたは戦略コンサルタントです。
以下の顧客情報をもとに、A4 1枚の提案書骨子を作ってください。
構成：タイトル／現状課題／施策／効果／費用／スケジュール
各セクション 150字以内。
---
顧客情報：
 ・業種：
 ・従業員数：
 ・現状の課題：
 ・予算感：
```

### パターンC：メール返信

**使うテンプレ**
```
あなたはビジネスメールのプロです。
以下のメールに対し、【謝意／自社の意向／次アクション】の3要素を含めて返信してください。
条件：敬語、200字以内、件名の案も1つ提案。
---
（受信メール本文）
```

## 2-4. 出力がイマイチな時の「調整フレーズ集」

送った後の追加メッセージで、返答の質を微調整できます。

| 直したい方向 | フレーズ例 |
|-------------|-----------|
| もっと短く | 「半分の長さにしてください」 |
| もっと詳しく | 「各項目に根拠を1文ずつ足してください」 |
| 堅く | 「官公庁向けのトーンに変えてください」 |
| 柔らかく | 「社内後輩への説明口調にしてください」 |
| 別案が欲しい | 「別の切り口であと2案出してください」 |
| 表にしたい | 「Markdown の表形式に整えてください」 |
| 日本語おかしい | 「自然な日本語に手直ししてください」 |
| 用語を揃えたい | 「『顧客』という単語に統一してください」 |

### ⚠️ 注意
出力に間違いがあったら、**指摘したうえで修正依頼**してください。
「ここ間違ってない？」と質問するだけだと、Claude は「すみません、確かに間違っていました」と素直に認めるものの、**あなたの指摘が正しいとは限りません**。事実は必ず自分で確認してください（後述の「ハルシネーション」参照）。

---

## 2-5. ⚠️ ハルシネーション（嘘をつく現象）に注意

**ハルシネーション** ＝ AI が自信満々に**間違った情報**を答えてしまう現象です。

### 起こりやすい質問
- 人名・数値・法律・日付など、事実確認が必要なもの
- 「◯◯という商品はいくらですか？」のような**最新情報**を求める質問
- 「この条文は何条？」のような**正確性が必須**の質問

### 対策
- 事実情報は **必ず一次情報（公式サイトや社内データ）で裏取り**する
- プロンプトに「**わからない場合は『不明』と答えてください**」と書くと、嘘を減らせる
- 重要な意思決定に使う場合は、Claude の回答を **人間が最終チェック**する

## よくあるつまずき Q&A

**Q1. テンプレを毎回コピペするのが面倒です**
A. iPhone の「設定 → 一般 → キーボード → ユーザー辞書」で、「ぷろ」と打つと提案書テンプレが出るように登録できます。

**Q2. 社外秘の情報を貼っていいのか不安です**
A. Max プランの有料ユーザーの会話は **AI の学習には使われません** が、社内規定で外部 AI 利用が禁止されていないか必ず事前確認してください。顧客の個人情報・契約書の実データは、まずは匿名化してから貼る習慣を。

**Q3. 返答が途中で切れます**
A. 「**続きをお願いします**」と打てば続きを書いてくれます。または最初から「2000字以内で」など長さを指定してください。
