# Claude 活用 初心者完全ガイド（1ヶ月ロードマップ）

このガイドは、プログラミング経験ゼロの方が、**1ヶ月で Claude（AI）を業務に活用できる**ようになることを目指した学習資料です。

社内でAI活用リーダーに立候補し、将来 AI 導入コンサルティングを行う方のために、
「顧客に自信をもって実例を示せるレベル」までを4週間でカバーします。

## 1ヶ月の学習カレンダー（目安）

### Week 1（1〜3日目）：まずは触ってみる
- Claude アプリを iPhone に入れる
- ログインして有料プラン（Max ×5）を確認する
- 初めてのチャットを送ってみる
- 音声入力でも質問してみる

### Week 2（4〜10日目）：上手に質問する技を身につける
- 「良い質問の5原則」を覚える
- 悪い質問 / 良い質問を10例比較する
- 議事録要約・提案書たたき台・メール返信を作る

### Week 3（11〜17日目）：ファイルを読ませる
- Excel・PDF・Word を添付して要約・分析してもらう
- Projects 機能でコンサル案件ごとに情報を蓄積する

### Week 4（18〜28日目）：PC で幅を広げる
- ブラウザで claude.ai を開く
- Artifacts で HTML・スライド・簡単な Python を生成する
- Claude Code とは何かを知り、2ヶ月目への橋渡しをする
- 自分の週次業務を棚卸しして AI 化リストを作る

## このガイドで**やらないこと**（2ヶ月目以降で扱います）

- Claude Code CLI を Windows にインストールする手順
- API を直接たたくプログラミング
- GitHub へのコード投稿や pull request 操作

まずは「チャット + 軽いファイル操作」を完璧にすることが目標です。
