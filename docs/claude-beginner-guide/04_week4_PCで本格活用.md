# Week 4. PC で本格活用 — ブラウザ・Artifacts・Claude Code への橋渡し

## この章で到達するゴール

- Windows 11 のブラウザで claude.ai を開き、iPhone と同じアカウントで続きの会話ができる
- **Artifacts（アーティファクト）** で HTML ページ・スライド・簡単な Python を生成できる
- Claude Code とは何かを理解し、2ヶ月目以降の学習計画が立てられる
- 自分の週次業務を棚卸しし、AI 化リストを 5 件以上作れる

所要時間：1週間（1日30分 × 7日）

---

## 4-0. なぜ PC でも使うのか？

iPhone は「思いついたときにサッと使える」のが強みですが、以下は PC（ブラウザ）のほうが圧倒的に効率的です。

- **長文を読む／書く**（議事録、提案書、レポート）
- **複数ファイルの比較**
- **生成した Python スクリプトを実際に動かす**
- **Artifacts**（インタラクティブなプレビュー）を大画面で確認

Week 4 はこの「**PC の強み**」を体験する週です。

---

## 4-1. ブラウザで claude.ai を開く

### 手順（Windows 11）

1. **Microsoft Edge** または **Google Chrome** を起動
2. アドレスバーに `claude.ai` と入力して Enter
3. **「Log in」** をクリック
4. **iPhone アプリと同じメールアドレス**でログイン
5. メール認証コードが届いたら入力
6. ログインできれば、**iPhone で昨日した会話がそのまま左側のリストに出る**

### 💡 ヒント
- アドレスバー右の ★（お気に入り）に登録しておく
- `Ctrl + Shift + D` で新規チャットを開くショートカットが使える（ブラウザ依存）
- 画面右上の「プラン」表示が **Max 20x** などになっているか確認

## 4-2. Artifacts で「目に見える成果物」を作る

**Artifacts** とは、Claude が生成した HTML・コード・図表を、右側のパネルで **プレビュー表示** してくれる機能です。

### 体験①：社内向け案内ページを作る

**プロンプト**
```
あなたは社内広報の Web デザイナーです。
「5月の全社 AI 勉強会」の告知ページを HTML + CSS で作ってください。

内容：
 ・日時：2026年5月15日 14:00-16:00
 ・場所：本社3F 大会議室
 ・対象：全社員（初心者歓迎）
 ・内容：Claude を使った業務効率化デモ
 ・申込方法：社内ポータルから

条件：
 ・スマホでも見やすいレスポンシブ
 ・会社カラーは青（#1E88E5）基調
 ・装飾は控えめ、Noto Sans JP フォント使用
```

送信すると、右側に**プレビュー**が出ます。修正も同じチャットで依頼できます：
```
ヘッダーをもう少し大きく、申込ボタンを目立つ黄色にして
```

### 体験②：簡単なプレゼンスライドを作る

**プロンプト**
```
あなたはコンサルタントです。
「中小企業向け AI 導入提案」の5枚スライドを、HTMLのスライド形式で作ってください。

1枚目：表紙
2枚目：AI 導入で何が変わるか
3枚目：当社がご提供する3つのサービス
4枚目：想定効果（数値例つき）
5枚目：次のステップ

各スライドは A4 横向きサイズ、左下にページ番号。
```

### 体験③：Excel 作業を肩代わりする Python スクリプト

**プロンプト**
```
私は Python を使ったことがありません。
以下を自動でやる Python スクリプトを書いてください。動かし方も手順で教えてください。

やりたいこと：
 ・フォルダ内の *.csv ファイルをすべて読み込む
 ・「売上」列を合計して、月ごとのシートにまとめる
 ・結果を「集計結果.xlsx」という Excel ファイルで出力する

環境：Windows 11 / Python は未インストール
初心者向けに、インストールから実行まで1ステップずつ書いてください。
```

Claude は **Python のインストール手順から実行方法まで**を初心者向けに書いてくれます。
実際に動かしてみることで、「業務自動化が本当にできる」感覚がつかめます。

### 💡 ヒント
- うまく動かなければ、**エラーメッセージをそのままコピペ**して Claude に貼れば、原因と対処を教えてくれます

## 4-3. Claude Code とは？（予告編）

**Claude Code** は、Claude を **ターミナル（黒い画面）** で使うための CLI（コマンドラインインターフェース）版です。
PC 上のファイルを直接読ませて、自動で編集・作成まで任せられます。

### ざっくり比較

| 使うもの | 向いている作業 | 難易度 |
|---------|--------------|--------|
| iPhone Claude アプリ | 外出先の質問・要約 | ★ |
| claude.ai（ブラウザ） | 資料作成・Artifacts | ★★ |
| Claude Code（CLI） | ファイルの自動編集・コード開発・反復作業 | ★★★★ |

### 本ガイドでは Claude Code の手順は扱いません

理由：
- Windows では WSL（Windows Subsystem for Linux）という前準備が必要で、初心者のつまずきポイントが多い
- ターミナル操作の基礎知識がないと、失敗時に原因がわからない
- **まずは Artifacts で「AI でコードが動く感覚」を掴むほうが効率的**

### 2ヶ月目の学習ロードマップ（予告）

Week 1〜4 を完走した後、興味があれば以下の順で進めてください：

1. **PowerShell の基礎**（3日）— コマンドとフォルダ操作に慣れる
2. **WSL のインストール**（1日）— Ubuntu を入れる
3. **Node.js のインストール**（1日）
4. **Claude Code のインストール**と初体験（2日）
5. **実ファイルを自動修正させる**演習（1週間）

このステップを踏むと、1ヶ月かかりますが確実に定着します。

## 4-4. 自分の週次業務を棚卸しする（AI 化ワーク）

コンサルとして顧客に提案するには、**まず自分で「AI 化候補の見つけ方」を知っている**必要があります。
以下のワークをあなた自身の業務でやってみましょう。

### ステップ1：1週間の業務をすべて書き出す

iPhone のメモか Excel に、1週間の業務を **30分刻み** で書き出します。
例：
- 月9:00-9:30 メール返信
- 月9:30-11:00 提案書作成
- 月11:00-12:00 A社訪問準備

### ステップ2：各業務に AI 活用度を ◎○△× で付ける

| 記号 | 意味 |
|------|------|
| ◎ | 90%以上AIに任せられる（要約、定型メール、データ集計） |
| ○ | 半分くらいAI補助（アイデア出し、ドラフト） |
| △ | 一部だけAI補助（ファクトチェック） |
| × | AI不向き（対面打ち合わせ、手作業） |

### ステップ3：◎の業務を AI 化する具体策を Claude に聞く

```
あなたは業務効率化コンサルです。
以下の私の業務（◎印）について、それぞれ「使うAI機能／手順／削減時間見込み」を教えてください。

 ・日次営業メール返信（毎日60分）
 ・週次営業会議の議事録作成（毎週45分）
 ・月次売上レポート作成（月末3時間）
```

### ステップ4：削減時間を試算する

各業務で削減できそうな時間を合計してみましょう。これが **あなた自身の AI 導入効果** です。
顧客への提案時に「私自身、月に◯時間削減できました」と語れるのが最強の営業トークになります。

## 4-5. 顧客への提案で使える **デモシナリオ3本**

コンサル訪問時に、その場で **iPhone を見せながら** デモできる 3 本を紹介します。

### デモ1：その場で議事録

打ち合わせ中の発言を音声入力で取り、その場で議事録化して「こうやって残せます」と見せる。

### デモ2：その場で提案書骨子

相手の業種・課題を聞き取り、その場で提案書のたたき台を生成。「目の前で1分で作れます」のインパクト大。

### デモ3：その場でエクセル分析

顧客から借りた（あるいは仮の）Excel を添付し、3行要約を見せる。「御社の◯◯業務ならこう使えます」と橋渡し。

## よくあるつまずき Q&A

**Q1. ブラウザで iPhone と同じ履歴が出ません**
A. ログインしているメールアドレスを確認してください。別アカウントで入っている可能性があります。

**Q2. Artifacts の HTML を社内で公開する方法は？**
A. 右上の **「Publish」** または **「Share」** で公開リンクが作れますが、社外秘情報を含む場合は**絶対にクリックしない**でください。代わりに、HTML をダウンロードしてメール添付で共有します。

**Q3. Python を動かす環境がわかりません**
A. Claude に「**Windows 11 で Python をインストールする手順を、初心者向けに画像無しで説明してください**」と聞けば、そのまま使える手順が出ます。迷ったら都度 Claude に聞けば OK です。

**Q4. 何もかも Claude に聞くクセがつきすぎないか心配です**
A. 逆です。**最初の1ヶ月は徹底的に Claude に聞きまくってください**。使い倒して初めて「これは AI 向き／これは人間向き」が感覚でわかります。それがコンサルとしての差別化になります。
