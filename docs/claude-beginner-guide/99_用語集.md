# 99. 用語集 — やさしい解説

本ガイドや AI 界隈でよく出てくる用語を、**中学生でも理解できる言い換え** で整理しました。
50 音順に並んでいます。わからない言葉が出てきたら、まずここを開いてください。

---

## あ行

### アプリ
スマホやPCに入れて使うプログラムのこと。LINEや Claude アプリもこれ。

### API（エーピーアイ）
Application Programming Interface の略。**プログラムからプログラムへ指示を出すための窓口**。たとえば Claude を自社システムに組み込みたいとき、API 経由で呼び出します。本ガイドでは扱いません。

### アーティファクト（Artifacts）
Claude.ai の機能名。Claude が作った HTML・コード・図表を **画面の右側にプレビュー表示** してくれる仕組み。スライドや Web ページを実際の見た目で確認できます。

### アカウント
サービスに登録した「あなた専用の入り口」のこと。メールアドレスとパスワードで入ります。

### アンソロピック（Anthropic）
Claude を作っているアメリカの会社。本社はサンフランシスコ。

---

## か行

### 課金（かきん）
有料プランにお金を払って加入すること。Max ×5 は Claude の高額プラン。

### 機械学習（きかいがくしゅう）
大量のデータから AI がパターンを学ぶ仕組み。Claude の裏でも使われている技術。

### クラウド
インターネットの向こうにあるコンピュータ。自分の PC の中ではなく、会社の外のサーバーで処理されること。

### CLI（シーエルアイ）
Command Line Interface の略。**黒い画面に文字だけを打って操作する方式**。Claude Code はこのタイプ。本ガイドでは扱いません。

### コマンド
CLI で打つ「命令文」。例：`ls`（ファイル一覧を表示）

---

## さ行

### サブスクリプション
月額で払い続ける料金形態。Claude Max もこれ。

### シェル
CLI でコマンドを受け付けるプログラム。Windows の PowerShell、Mac の zsh など。

### スクリプト
短いプログラムのこと。「エクセルを集計する Python スクリプト」のように使う。

### 精度（せいど）
AI の回答がどれくらい正確か。100% ではないので、人間の確認が必要。

### セキュリティ
情報を守ること。社外秘を AI に貼るときは会社のルール確認が必須。

---

## た行

### ターミナル
CLI を表示する黒い画面そのもの。Windows なら「PowerShell」「コマンドプロンプト」、Mac なら「ターミナル」アプリ。

### チャット
文字での会話。Claude との対話はすべてチャット形式。

### トークン
AI が文章を扱うときの「最小単位」。日本語は1文字あたり約1トークン。長文を貼ると多くのトークンを消費する。

---

## な行

### ナレッジ（Knowledge）
Projects 機能で、案件共通情報を入れておく場所。「Project knowledge」と呼ばれる。

---

## は行

### ハルシネーション（Hallucination）
AI が **自信満々に嘘をつく** 現象。日本語では「幻覚」と訳される。防ぎきれないので、**事実は必ず人間が確認** すること。

### パスワード
アカウントを守る合言葉。使い回しは危険。

### ファインチューニング
AI を特定業務向けに追加学習させること。本ガイドでは扱いません。

### プラン
サービスの契約コース。Free（無料）／ Pro ／ Max ／ Max 20x などの段階がある。

### プロジェクト（Projects）
Claude.ai の機能名。複数の会話とファイルをひとつの「箱」にまとめて管理できる。案件ごとに作るのがおすすめ。

### プロンプト（Prompt）
AI への指示文のこと。プロンプトの質 = AI 出力の質。

### ブラウザ
Web サイトを見るアプリ。Microsoft Edge, Google Chrome, Safari など。

---

## ま行

### マークダウン（Markdown）
文章にちょっとした装飾をつける簡単な記法。このガイドも Markdown で書かれている。`# 見出し`、`- 箇条書き` など。

### モデル
AI の「脳」にあたる部分。Claude にも複数バージョンがあり、Opus / Sonnet / Haiku などと呼ばれる（賢さ・速さ・価格が異なる）。

---

## や行

### ユーザー辞書
iPhone で「よく使う文字列」を短い読み方で登録できる機能。プロンプトテンプレの登録に便利。

---

## ら行

### リポジトリ（Repository）
ファイルの保管箱。GitHub というサービスで使われる用語。今あなたのチームが使っているのがこれ。

### LLM（エルエルエム）
Large Language Model の略。**大規模言語モデル**。Claude・ChatGPT・Gemini などはすべて LLM。

### ログイン
アカウントに入ること。メールアドレスとパスワードで入ります。

---

## わ行

### Word（ワード）
Microsoft の文書作成ソフト。拡張子は `.docx`。Claude に添付可能。

### Web
インターネット上のこと。Web 版 = ブラウザで使う版。

### WSL（ダブリューエスエル）
Windows Subsystem for Linux の略。Windows の中に Linux を動かす機能。Claude Code CLI を使うのに必要。本ガイドでは扱いません（2ヶ月目以降）。
