# Week 1. セットアップ編 — iPhoneで Claude と初対面

## この章で到達するゴール

- iPhone に Claude 公式アプリが入っている
- アプリにログインでき、**Max ×5 プラン**が有効になっていることを自分で確認できる
- Claude と日本語で会話できる
- 音声入力でも質問できる

所要時間：初日 1 時間ほど。慣れれば 10 分で完了する内容です。

---

## 1-1. Claude 公式アプリをインストールする

### 手順

1. iPhone のホーム画面から **「App Store」** を開く
2. 画面下の **「検索」** をタップ
3. 検索バーに **claude** と入力
4. **「Claude by Anthropic」** という青いロゴのアプリを探す
   - 開発者名が **「Anthropic, PBC」** になっているか必ず確認
   - ⚠️ 似た名前の偽アプリが存在することがあります。必ず開発者名を確認してください
5. 右横の **「入手」** または **雲マーク** をタップ
6. Face ID または Touch ID で認証
7. ダウンロードが終わったら **「開く」** をタップ

### 💡 ヒント
- 「Anthropic（アンソロピック）」が Claude を作っている会社の名前です

---

## 1-2. ログインと Max ×5 プランの確認

### 手順

1. アプリを開くと **「ログイン」または「Sign in」** 画面が出る
2. すでに課金時に使ったメールアドレスでログイン
   - Google アカウントで登録した場合は **「Continue with Google」** をタップ
   - メール＋パスワードで登録した場合はそれぞれ入力
3. 認証コードがメールに届くので、6 桁の数字を入力
4. ホーム画面（チャットが打てる画面）が表示されれば成功

### プランを確認する

1. 画面左上の **三本線（≡）メニュー** をタップ
2. **「Settings」または「設定」** をタップ
3. **「Account」または「アカウント」** をタップ
4. **「Plan」** の欄に **Max** または **Max 20×** などと表示されているか確認
   - 「Free」となっていたら課金が紐づいていません
   - その場合、「Manage subscription」→「Restore purchase」でリカバリ可能

### ⚠️ 注意
- 支払いに使った Apple ID と、Claude にログインしているメールアドレスが **違うアカウント** だと、プランが紐づかないことがあります
- その場合は Anthropic のサポート（support@anthropic.com）にメールしてください

## 1-3. はじめてのチャット

### 手順

1. アプリのホーム画面の下部に **「Message Claude...」** と書かれた入力欄がある
2. タップして、以下の文を打ってみる
   ```
   こんにちは。私はこれから Claude を業務で活用したい完全初心者です。何から学ぶと良いですか？
   ```
3. 右の **紙飛行機マーク** をタップして送信
4. Claude が日本語で丁寧に返してくれる

### おすすめの最初の質問 3 つ

業務で使える感覚をつかむため、順に打ってみてください。

- **質問①**：
  ```
  「明日の定例会議のアジェンダを3つに整理したい」とだけ伝えたら、
  どんな追加情報があれば精度が上がりますか？
  ```
- **質問②**：
  ```
  以下のメールを丁寧語で3行に要約してください。
  ---
  （ここに社内メールを貼り付け）
  ```
- **質問③**：
  ```
  AI 導入コンサルとして顧客に提案する際、
  最初に聞くべき質問を5つ、優先順位付きで教えて。
  ```

## 1-4. 音声入力を使う

手が離せないとき・歩きながらでも質問できるので、必ず一度試してください。

### 手順

1. チャット入力欄の **右下にあるマイクアイコン** をタップ
2. iPhone が「音声入力の許可」を求めるので **「許可」**
3. マイクに向かって日本語で話す
   - 例：「先月の売上レポートを3点に要約する骨子を教えて」
4. 話し終わったら **停止ボタン** をタップ
5. 文字起こしされた内容が入力欄に入るので、確認して送信

### 💡 ヒント
- 句読点は自動で入りません。「、」「。」と言うと句読点が入ります
- 会議中・車内などの雑音が多い環境では精度が落ちます

---

## 1-5. 履歴（過去の会話）を管理する

Claude の会話は左側のメニューにすべて残ります。業務で使う上で、履歴管理は大事です。

### 手順

1. 画面左上の **三本線（≡）** をタップ
2. **「Recents」** に過去の会話一覧が表示される
3. 各会話を **長押し** すると、以下のメニューが出る
   - **Rename**：会話にタイトルをつける（例：「4/20 営業部議事録要約」）
   - **Delete**：削除
   - **Star**：お気に入り登録

### 💡 ヒント
- 会社の機密情報を扱った会話は、使い終わったら削除する習慣をつけると安全です
- 顧客ごとに「◯◯社_提案_2026-04」のような命名ルールを作ると、後から探しやすくなります

## よくあるつまずき Q&A

**Q1. ログインしようとしたら「アカウントが見つかりません」と出ます**
A. 課金時に使ったメールと別のメールで入ろうとしている可能性があります。請求メール（Anthropic から届く領収書）に書かれているメールアドレスを確認してください。

**Q2. 日本語で返事が来ません**
A. 最初に「日本語で答えてください」と一度お願いすると、その会話では日本語固定になります。全体設定は `Settings → Appearance → Language` から変更可能です。

**Q3. プラン欄が「Free」のままです**
A. アプリを一度完全に閉じ（ホームバーでスワイプアップ）、再起動して再ログインしてください。それでもダメなら、`Settings → Manage subscription → Restore purchase` を試します。

## Week 1 の宿題

以下を実際にやって、スクリーンショットを残しておいてください（自分用の記録として）。

1. ✅ 今日届いた業務メールを 1 通、Claude に**3行で要約**させる
2. ✅ 明日の予定（カレンダー上の3件）を Claude に貼り付けて、**優先順位を提案**してもらう
3. ✅ 音声入力で「今週の業務で一番時間がかかった作業は何か」を**自分で口にしてから**、Claude に改善案を聞く
