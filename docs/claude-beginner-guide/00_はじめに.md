# 00. はじめに

## このガイドの対象者

- プログラミング経験が**まったくない**方
- スマートフォン（iPhone）は普段使っているが、PC での専門的な操作は苦手な方
- 会社の業務で AI（Claude）を活用し、将来は顧客に AI 導入を提案する立場になりたい方

## このガイドを読み終わると、何ができるようになる？

4週間読み進めて宿題をこなすと、以下のことができるようになります。

1. **iPhone だけで** Claude に業務文書の要約・下書きを任せられる
2. Excel・PDF・Word ファイルを Claude に読ませて、集計や論点整理をしてもらえる
3. 顧客に対して「御社の業務ならこう使えます」と **具体例 20 種類**から選んで提案できる
4. 自分の定常業務の中から「AI 化できる作業」を棚卸しできる
5. PC（Windows 11）のブラウザで Claude を開き、Python スクリプトを書かせて Excel 作業を自動化できる

## このガイドの使い方

### 原則：週1章ずつ、必ず「宿題」をやる

読むだけでは身につきません。各章の末尾にある **宿題** を、実際の業務資料で試してください。

### 推奨タイミング

- **朝の10分**：前日の業務メールを Claude に要約させる
- **会議直後の5分**：議事メモを Claude で清書させる
- **帰る前の15分**：翌日の提案書ドラフトを作ってもらう

この「**1日30分 × 30日**」が、1ヶ月後にそこそこ使える自分を作ります。

## 本書の表記ルール

- **「」で囲まれた文字** は、画面上のボタンやメニュー名を指します
  - 例: 画面右上の「設定」をタップ
- **太字** は、特に重要な用語です
- **コード風の枠** は、Claude に打ち込む文章例です
  ```
  あなたは営業部長です。以下の議事録を3行で要約してください。
  ```
- **💡 ヒント** は、知っていると得するコツです
- **⚠️ 注意** は、やってしまいがちな失敗です

## 専門用語が出てきたら

初めて出てきた用語は、その場で **（注：意味）** のように注釈がつきます。

それでもわからない言葉があれば、[99_用語集.md](./99_用語集.md) を開いてください。50音順で並んでいます。

## サポート環境

このガイドは、以下の環境を想定しています。

- **スマホ**: iPhone（iOS 17 以降）
- **PC**: Windows 11
- **プラン**: Claude Max ×5（またはそれ以上）
- **ブラウザ**: Microsoft Edge または Google Chrome

Android や Mac でも手順は **9割同じ** ですが、画面表示が多少異なる場合があります。
