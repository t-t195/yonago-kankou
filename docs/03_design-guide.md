# 03. デザインガイド

## コンセプト

「山陰の風土 × 信頼感」。旧版のポップなインフォグラフィック調から、事業サイトとして信頼性のある和モダン基調へ刷新。大山の緑・日本海/中海の藍・夕景のオレンジを基調にする。

## カラーパレット

| 役割 | 色 | 用途 |
|---|---|---|
| プライマリ | `#1B3A5C`（藍） | 見出し・ヘッダー・フッター |
| セカンダリ | `#2E7D5B`（大山グリーン） | タグ・サブ見出し・無料バッジ |
| アクセント | `#E8734A`（夕陽オレンジ） | CTA・★評価・強調 |
| ベース | `#FAF7F2`（生成り） | 背景 |
| サーフェス | `#FFFFFF` | カード背景 |
| テキスト | `#2A2A2A` / `#5C5C5C` | 本文 / 補足 |

コントラスト比: 本文・ボタンは WCAG AA（4.5:1）以上を確保。

## タイポグラフィ（Google Fonts・無料）

- 見出し: **Shippori Mincho**（明朝・和の品格）
- 本文: **Noto Sans JP**（可読性）
- 数値・英字: Noto Sans JP 700

サイズスケール: 14 / 16 / 18 / 22 / 28 / 36 / 48px（モバイルは1段階縮小）

## コンポーネント

- **カード**: 白背景、角丸16px、上辺に評価色ボーダー（★3=オレンジ/★2=緑/★1=藍）、hoverで浮上
- **タグ**: ピル型、目的=藍系・感情=緑系
- **CTAボタン**: オレンジ塗り、角丸999px、hover暗転
- **テーブル**: 行ストライプ、1列目固定見出し
- **タイムライン（モデルコース）**: 左ボーダー + ドット

## ビジュアル方針

- 写真素材は現時点で権利クリアなものがないため、**CSSグラデーション + 大山シルエットのインラインSVG**で構成（著作権リスクゼロ）。
- 公開前に実写真（自前撮影 or 写真AC等の無料素材）への差し替えを推奨。差し替え位置はHTMLコメント `<!-- PHOTO: -->` で明示。
