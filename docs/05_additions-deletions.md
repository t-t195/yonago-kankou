# 05. 追加・削除まとめ & 費用確認事項

ご指示「追加で必要な行動やツールは追加、不要なものは削除、まとめて追記」に基づく変更一覧です。

## 追加したもの

| 追加項目 | 理由 |
|---|---|
| 戦略ドキュメント一式（docs/01〜04） | 目的・競合・強み・AIO/SEO方針を制作物と紐づけて管理するため |
| 料金比較「表」セクション | 旧版はChart.jsのグラフ＝クローラ/AIが読めない。表は SEO・AIO に直接効く |
| 目的別ガイド・モデルコース3種 | 競合（公式・大手メディア）が弱い意思決定支援コンテンツ＝差別化の核 |
| FAQセクション + FAQPage構造化データ | AI検索（AI Overviews等）に引用されやすい一問一答形式 |
| 運営者情報・代表メッセージセクション | E-E-A-T対策。検索・AI双方で信頼性評価に直結（記入は【要編集】） |
| 構造化データ JSON-LD（WebSite / ItemList(TouristAttraction) / FAQPage） | リッチリザルト・AI引用対策 |
| OGP・canonical・meta description | SNSシェア・検索表示の最適化 |
| sitemap.xml / robots.txt | 検索エンジンへのインデックス促進 |
| llms.txt | コストゼロのため設置。ただしGoogleは2026年5月に「利用しない」と表明済みで効果は限定的（保険扱い） |
| privacy.html（プライバシーポリシー） | 解析ツール導入・問い合わせ受付に必要な法務面の整備 |
| Googleマップ埋め込み（無料iframe版） | アクセス案内。APIキー不要の埋め込み方式のため費用ゼロ |
| モバイルナビ等の自前CSS/JS | 旧版のCDN依存をなくし表示速度・安定性を改善 |

## 削除したもの

| 削除項目 | 理由 |
|---|---|
| Tailwind CSS（CDN版） | CDN版は本番非推奨（公式明言）・表示速度低下。自前CSSに置換 |
| Chart.js + グラフ3種（料金棒/目的ドーナツ/感情レーダー） | グラフ内のテキストは検索・AIに読めずSEO上無価値。料金は表へ、目的・感情はタグと目的別ガイドへ情報を移設（データ自体は捨てていません） |
| インフォグラフィック調のポップ配色 | 事業サイトとしての信頼感を優先し和モダン基調に刷新 |

## 費用が発生しうるもの（ご確認ください）

**今回の実装に有料APIは一切使っていません。** 以下は今後の判断事項です。

| 項目 | 費用 | 状態 |
|---|---|---|
| Google Maps **JavaScript API** | 従量課金（要クレジットカード登録） | **不採用**。無料のiframe埋め込みで代替済み。地図のカスタマイズが必要になった場合のみ要検討 |
| 独自ドメイン | 年1,000〜2,000円程度 | 未取得。GitHub Pagesなら無料サブドメインで公開可能 |
| レンタルサーバー | 月500〜1,000円程度 | 不要（静的サイトのため無料ホスティングで十分）。WordPress化する場合のみ |
| 有料写真素材（PIXTA等） | 1点数百円〜 | 不要。自前撮影 or 写真AC等の無料素材で代替可 |
| Google Fonts / Search Console / GA4 / GitHub Pages | 無料 | 採用・採用予定 |
