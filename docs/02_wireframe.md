# 02. サイトマップ & ワイヤーフレーム

## サイトマップ

```
/ (index.html)  ……… ワンページLP構成（観光ガイド + 事業者情報）
├── #about      ……… このサイトについて
├── #spots      ……… 厳選スポット8選
├── #compare    ……… 料金比較表
├── #purpose    ……… 目的別ガイド
├── #courses    ……… モデルコース
├── #faq        ……… よくある質問
├── #operator   ……… 運営者情報・代表メッセージ
├── #access     ……… アクセス・マップ
└── privacy.html …… プライバシーポリシー
robots.txt / sitemap.xml / llms.txt
```

LP（ワンページ）構成とした理由: コンテンツ量が1テーマ・8スポットに収まり、回遊より縦読みの説得構造が適するため。スポット個別ページ化は記事数が増えた段階で分割（拡張余地はサイトマップに確保済み）。

## 画面遷移・インタラクション

- ナビ: スムーススクロール（CSS `scroll-behavior`）、モバイルはハンバーガー開閉のみJS使用
- FAQ: `<details>/<summary>`（JSなし・クローラに全文見える）
- カードhover: 浮き上がり（CSSのみ）
